## 로컬 실행

`index.html`은 빌드가 필요 없다. 다만 **열는 방법에 따라 되는 기능이 다르다.**

### 파일을 그냥 열면 (`file://`)

브라우저가 위치 권한을 막아서 **모의 모드로만 동작한다.** 연출과 화면 확인에는 충분하다.

### 서버로 열면 (`http://localhost`)

위치 정보가 살아난다. GPS를 테스트하려면 이 방법을 써야 한다.

```bash
python -m http.server 8000
```

그다음 `http://localhost:8000` 을 연다. Node가 있으면 `npx serve` 도 된다.

### 폰에서 실제 GPS로 테스트할 때

`localhost`가 아닌 주소에서는 **`https://`가 필수다.** `http://192.168.x.x` 로는 위치 권한이 안 난다. 가장 간단한 방법은 Cloudflare Pages나 Vercel 무료 티어에 올리는 것이다 — 정적 파일 하나라 설정이 거의 없다.

### 알아둘 것

- **여권은 기기마다 따로다.** `localStorage`(여권·기록)와 IndexedDB(사진)에 저장되므로 기기를 바꾸면 새로 발급된다. 설정집에서 이걸 "여권 분실"로 흡수해뒀고, 계정 기능은 반응을 보고 붙이기로 했다
- 사진은 480px JPEG로 줄여 **기기에만** 저장된다. 전송 코드가 없다
- 도장 소리는 Web Audio로 합성한다. 오디오 파일이 없다
- 모의 모드 패널은 여권 화면 맨 아래. 심사 분기 5종을 강제할 수 있다

## 답사 후 고칠 곳

**판정 코드는 다 썼다. 이제 남은 건 데이터뿐이다.**

②판정 함수와 ③분기 교체는 끝났고 자가 진단 25개가 통과한다. `CFG.boundary`가 `null`이라 아직 모의 모드일 뿐이다. **좌표를 채우는 순간 실제 판정이 켜진다.**

### ① 데이터 — `index.html` 상단 `CFG`

```js
const CFG = {
  boundary: null,            // ← 우두동 경계 폴리곤 [[lat,lng], ...]
  bufferM: 50,
  exitBandM: 1000,           // 출국 심사를 받는 국경 일대
  checkinHours: [7, 21],
  excluded: [],              // ← 아파트 11개 단지 + 시설 5곳
  bridges: [],               // ← 다리. {id, name, end:[lat,lng], hasFootway, walkMin}
  maxAccM: 200,              // 측위 오차가 이보다 크면 판정하지 않는다
  rate: { officialMinPerGak: 15, seedObservations: [] }  // ← 실측 대기 분
};
```

- `boundary`를 채우면 **모의 모드가 자동으로 꺼진다** (`S.sim = !CFG.boundary`)
- `excluded`는 `{name, reason, center:[lat,lng], radiusM}` 배열. 아파트 단지 11곳과 군 시설·명진학교·재활병원·소양초. 반경은 **넉넉하게**
- `seedObservations`에 답사에서 직접 기다린 분을 넣는다. 첫 방문자가 "환율 데이터 없음"을 보지 않게 하는 씨앗값
- `bridges`의 `end`가 채워지면 입국 승인서의 통과 지점이 **가장 가까운 다리 이름**으로 바뀐다. 비어 있으면 "소양2교"로 고정
- 값은 답사 체크리스트 §7 JSON에서 그대로 옮긴다

미션 좌표는 `MISSIONS` 배열의 `verify:"geo"` 항목에 이미 자리가 있다. `coord:null`을 실측값으로 바꾸면 된다.

```js
{ id:9, ..., verify:"geo", coord:null, radiusM:30 }   // ← coord 만 채운다
```

반경은 9·13·14번 30~50m, 11번(우두벌) 60m, 12번 40m로 잡아뒀다. **30m 아래로 좁히지 않는다.** GPS 오차로 실패한다.

미션 10번만 모양이 다르다. 두 강을 각각 찍어야 해서 `points` 배열이다.

```js
{ id:10, points:[{ key:"bukhan", name:"북한강", coord:null, radiusM:40 },
                 { key:"soyang", name:"소양강", coord:null, radiusM:40 }], sameDay:true }
```

### ② 판정 함수 — 완료

`withinHours()` 아래 "지오펜스 판정" 구역에 있다. 앞의 셋은 CFG와 무관한 순수 함수고, 뒤의 넷이 CFG를 읽는다.

```js
distM(aLat,aLng,bLat,bLng)   // haversine
inPoly(lat,lng,poly)         // ray casting. 감김 방향 무관, 오목 다각형 가능
distToEdgeM(lat,lng,poly)    // 다각형 변까지 최단 거리

inside(lat,lng)              // 영토 안인가. 경계 밖 bufferM 까지 통과
borderDistM(lat,lng)         // 경계까지 거리. 안이면 0
nearExcluded(lat,lng,accM)   // 금지 구역. 측위 오차만큼 반경을 불린다
nearPoint(lat,lng,m)         // m.coord 단일 또는 m.points 배열
nearestBridge(lat,lng)       // 통과 지점 표기용
```

**`false`와 `null`을 섞지 않는다.** `false`는 판정 결과가 "밖"이라는 뜻이고, `null`은 판정할 데이터가 아직 없다는 뜻이다. `CFG.boundary`가 비어 있으면 `inside()`는 `null`을 돌려준다.

금지 구역은 **측위 오차만큼 반경이 불어난다.** 오차 원이 구역에 닿기만 해도 도장을 주지 않는다. "입국은 관대하게, 금지는 엄격하게, 애매하면 도장 없음"을 그대로 구현한 것이다. 오차가 `maxAccM`(200m)보다 크면 아예 판정하지 않고 다시 신고하게 한다.

### ③ 분기 교체 — 완료

`runControl()`은 `S.sim`이 `false`일 때 실제로 판정한다. **순서가 규칙이다.**

1. 심사 시간 (헌법 제11조)
2. 위치 권한 거부 / 측량 실패
3. 측위 정밀도 (`maxAccM` 초과면 거부)
4. **금지 구역** (헌법 제12조) — 국경보다 먼저 본다
5. 영토 밖 — 남은 거리와 가장 가까운 다리를 알려준다

금지 구역 문구는 `FORBID_REASON`이 `reason`별로 고른다. **단지명은 화면에 쓰지 않는다.**

`runExit()`(출국)도 같은 순서를 지나가되 **영토 판정만 뒤집힌다.** 입국은 "안에 있어야" 통과고, 출국은 "밖에 있어야" 통과다. `inside()` 한 줄이 두 방향 모두를 맡는다 — 완충 `bufferM`이 입국에서는 "경계 밖 50m까지 봐준다"였다가 출국에서는 "경계 밖 50m까지는 아직 나간 게 아니다"가 되므로, 애매한 띠가 양쪽에서 미발급 쪽으로 간다.

다리와의 거리로는 판정하지 않는다. 우두동은 두 강으로 둘린 땅이라 영토를 벗어났다는 사실 자체가 다리를 건넜다는 뜻이고, `nearestBridge`로 판정하면 다리까지 갔다 되돌아선 사람에게도 도장이 나간다. 다리는 통과 지점 표기에만 쓴다. 다만 국경에서 `exitBandM`(1km) 밖이면 받지 않는다. 집에 돌아가 누른 출국은 다리를 건너며 받은 도장이 아니다.

출국은 **체류 중인 여권에만** 열린다(`staying()`). 마지막 입국 뒤에 출국이 없어야 체류 중이다. 재입국은 몇 번이든 된다.

양쪽 다 `inside()`가 `null`이면 "국경을 판정할 수 없습니다"로 따로 떨어뜨린다. **`null`을 "밖"이나 "안"으로 덮어 말하지 않는다.** `exitBandM`이 비어 있어도 띠는 1km로 살아 있다.

심사가 실제로 측량에 성공하면 국경까지 거리를 `S.lastFix`에 남긴다. 여권 홈의 버튼이 10분 동안 그 거리를 함께 보여준다 — "입국 심사 받기 · 국경까지 2.4km"(화면설계 S5의 *비활성 대신 정보 제공*). **홈에서 위치를 다시 읽지는 않는다.** 앱을 열자마자 권한 창을 띄우지 않기 위해서다. 그래서 좌표를 채우기 전에는 이 표시가 나오지 않는다.

`checkGeo(m)`도 같은 순서로 판정하고, 통과하면 소리·진동·텍스트 3중으로 알린다. 미션 10처럼 `points`가 있는 과업은 지점별로 `p.geo[미션id][지점key]`에 쌓이고, `sameDay` 조건을 채우면 그때 `p.done`에 들어간다. 한 번 발급된 도장은 나중 방문으로 취소되지 않는다.

### 자가 진단 — 좌표 없이 지금 확인할 수 있다

여권 화면 맨 아래 모의 패널에 **판정 자가 진단**이 있다. 25개 항목이 시험 도형으로 판정 수학을 직접 검증한다. 평소엔 접혀 있고 실패가 있으면 펼쳐진 채 빨갛게 뜬다.

답사에서 `CFG`를 채운 뒤에도 한 번 더 열어 보면 된다. 전부 통과인데 실제 판정이 이상하면 수학이 아니라 **좌표가 틀린 것이다.**

## 지켜야 할 선

코드를 고칠 때 이 선은 기능이 아니라 안전 요건이다.

- **아파트를 대상으로 하는 미션을 만들지 않는다.** 표지석·단지명·외관 사진도 포함. 7,885세대가 사는 주거지다 (헌법 제12조)
- **군 시설·명진학교·재활병원·소양초를 지오펜스에서 제외한다.** 입국 판정은 관대하게(+50m), 금지 구역은 엄격하게. 애매하면 도장을 주지 않는다
- **체크인 시간은 07:00–21:00** (헌법 제11조)
- **역사 섹션에서는 농담하지 않는다.** 기록은 "적혀 있습니다", 전승은 "전해집니다", 학설은 "견해가 있습니다", 모르는 건 "모릅니다". 원고 문서의 어휘 규칙을 따른다
- **가게를 평가하지 않는다.** 순위·별점 금지. 비공식 지정임을 표기하고 삭제 요청 창구를 둔다
- **비공식 고지를 모든 화면에 남긴다**
- **주인색 `#C1382B`는 도장에만 쓴다.** 다른 데 쓰면 도장 찍히는 3초가 특별해지지 않는다
- **접근성**: 입국 연출 각 단계를 `aria-live`로 알리고, 도장 획득은 소리·진동·텍스트 3중으로 전달한다. `prefers-reduced-motion`을 지킨다. 우두동에 시각장애인 특수학교가 있다
  - 알림 영역(`#live`)은 **`#app` 밖에 한 번만 둔다.** `render()`가 `#app`을 통째로 비우므로 안에 두면 단계마다 노드가 새로 생기고, 내용이 든 채로 삽입된 live 영역은 읽히지 않는 일이 잦다
