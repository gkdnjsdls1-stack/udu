# 우두국

춘천시 우두동을 "입국 심사가 필요한 작은 나라"로 설정한 위치 기반 웹앱.
다리를 건너 입국 도장을 받고, 국가 과업을 수행하고, 공유 카드를 남긴다.

1인 제작 · 빌드 과정 없음 · 외부 연동 없음

> 우두국은 춘천시와 무관한 비공식 창작물이다.

## 로컬 실행

`index.html`은 빌드가 필요 없다. 다만 **열는 방법에 따라 되는 기능이 다르다.**

### 파일을 그냥 열면 (`file://`)

브라우저가 위치 권한을 막아서 **모의 모드로만 동작한다.** 연출과 화면 확인에는 충분하다.

### 서버로 열면 (`http://localhost`)

위치 정보가 살아난다. GPS를 테스트하려면 이 방법을 써야 한다.

```bash
python -m http.server 8000
```

그다음 `http://localhost:8000` 을 연다. Node가 있으면 `npx serve` 도 된다.

### 폰에서 실제 GPS로 테스트할 때

`localhost`가 아닌 주소에서는 **`https://`가 필수다.** `http://192.168.x.x` 로는 위치 권한이 안 난다. 가장 간단한 방법은 Cloudflare Pages나 Vercel 무료 티어에 올리는 것이다 — 정적 파일 하나라 설정이 거의 없다.

### 알아둘 것

- **여권은 기기마다 따로다.** `localStorage`(여권·기록)와 IndexedDB(사진)에 저장되므로 기기를 바꾸면 새로 발급된다. 설정집에서 이걸 "여권 분실"로 흡수해뒀고, 계정 기능은 반응을 보고 붙이기로 했다
- 사진은 480px JPEG로 줄여 **기기에만** 저장된다. 전송 코드가 없다
- 도장 소리는 Web Audio로 합성한다. 오디오 파일이 없다
- 모의 모드 패널은 여권 화면 맨 아래. 심사 분기 5종을 강제할 수 있다

## 답사 후 고칠 곳

**이게 다음 작업의 핵심이다.** 지금은 지오펜스 좌표가 없어서 실제 위치 판정을 하지 않는다.

순서대로 보면 ① 데이터를 채우고 ② 판정 함수를 새로 쓰고 ③ 기존 분기를 그 함수로 교체하는 일이다. ②는 **아직 코드가 없다.**

### ① 데이터 — `index.html` 상단 `CFG`

```js
const CFG = {
  boundary: null,            // ← 우두동 경계 폴리곤 [[lat,lng], ...]
  bufferM: 50,
  checkinHours: [7, 21],
  excluded: [],              // ← 아파트 11개 단지 + 시설 5곳
  rate: { officialMinPerGak: 15, seedObservations: [] }  // ← 실측 대기 분
};
```

- `boundary`를 채우면 **모의 모드가 자동으로 꺼진다** (`S.sim = !CFG.boundary`)
- `excluded`는 `{name, reason, center:[lat,lng], radiusM}` 배열. 아파트 단지 11곳과 군 시설·명진학교·재활병원·소양초. 반경은 **넉넉하게**
- `seedObservations`에 답사에서 직접 기다린 분을 넣는다. 첫 방문자가 "환율 데이터 없음"을 보지 않게 하는 씨앗값
- 값은 답사 체크리스트 §7 JSON에서 그대로 옮긴다

### ② 판정 함수 — 새로 써야 한다

현재 없는 코드다. 세 개가 필요하다.

```js
function inside(lat, lng)            // 점-다각형 판정 + bufferM
function nearExcluded(lat, lng)      // excluded 중 하나의 반경 안인가
function nearPoint(lat, lng, m)      // 미션 m의 좌표에서 radiusM 안인가
```

점-다각형은 ray casting으로 20줄이면 된다. 거리는 haversine이면 충분하다.

**미션 데이터에 좌표가 아직 없다.** `MISSIONS` 배열의 `verify:"geo"` 항목(9~14)에 `coord`와 `radiusM`을 추가해야 한다.

```js
{ id:9, ..., verify:"geo", coord:[0,0], radiusM:30 }
```

정상 판정 반경은 30m 이상 권장. 좁게 잡으면 GPS 오차로 실패한다.

### ③ 분기 교체 — `runControl()`

지금은 이렇게 되어 있다.

```js
const sim = S.sim ? S.simCase : "ok";   // 모의가 아니면 항상 통과
```

`S.sim`이 `false`일 때 **실제 판정이 들어가야 한다.**

- `nearExcluded()` → 금지 구역 분기 (헌법 제12조)
- `!inside()` → 국경 밖 분기 + 실제 거리 표시
- 통과 시 `c.place`를 가장 가까운 다리 이름으로

`checkGeo(m)`도 고쳐야 한다. 현재는 위치를 받기만 하고 **거리를 비교하지 않는다.** `nearPoint()` 비교를 넣는다.

### ④ 그 외 빈칸

| 자리 | 채울 것 |
|---|---|
| `HISTORY.m13` 의 `slot` | 유적 연대. 현장 안내판에서 확인 |
| `MISSIONS` 14번 | 우두성 추정지를 못 찾으면 **삭제**. 원고가 아깝다고 아무 강변에서 재생시키지 않는다 |
| `drawCard()` 하단 | `udu.example` → 실제 도메인 |
| `MISSIONS` 9번 | 등산로가 없으면 "정상 등정"을 "조망 촬영"으로 바꾸고 16번과 합친다 |

### ⑤ 답사로는 안 풀리는 것

- **TAGO API에 춘천 정류소가 있는지** — 공공데이터포털에서 국토부 TAGO 버스도착정보(15098530) 키를 발급받아 실제로 호출해본다. 안 나오면 정적 시간표로 간다
- 2026.9.30 버스 개편의 우두동 영향 — 춘천시 교통 부서
- 우두성 추정지 — 춘천시청 문화재 담당, 국립춘천박물관

## 지켜야 할 선

코드를 고칠 때 이 선은 기능이 아니라 안전 요건이다.

- **아파트를 대상으로 하는 미션을 만들지 않는다.** 표지석·단지명·외관 사진도 포함. 7,885세대가 사는 주거지다 (헌법 제12조)
- **군 시설·명진학교·재활병원·소양초를 지오펜스에서 제외한다.** 입국 판정은 관대하게(+50m), 금지 구역은 엄격하게. 애매하면 도장을 주지 않는다
- **체크인 시간은 07:00–21:00** (헌법 제11조)
- **역사 섹션에서는 농담하지 않는다.** 기록은 "적혀 있습니다", 전승은 "전해집니다", 학설은 "견해가 있습니다", 모르는 건 "모릅니다". 원고 문서의 어휘 규칙을 따른다
- **가게를 평가하지 않는다.** 순위·별점 금지. 비공식 지정임을 표기하고 삭제 요청 창구를 둔다
- **비공식 고지를 모든 화면에 남긴다**
- **주인색 `#C1382B`는 도장에만 쓴다.** 다른 데 쓰면 도장 찍히는 3초가 특별해지지 않는다
- **접근성**: 입국 연출 각 단계를 `aria-live`로 알리고, 도장 획득은 소리·진동·텍스트 3중으로 전달한다. `prefers-reduced-motion`을 지킨다. 우두동에 시각장애인 특수학교가 있다

## 배포

정적 파일 하나다. Cloudflare Pages나 Vercel 무료 티어에 올리면 끝이다.

- `https://`여야 GPS가 동작한다
- 첫 로드 300KB 이하를 유지한다. 바이럴로 들어온 사람의 첫 인상이 로딩이면 거기서 끝난다
- 웹폰트(Noto Serif KR)는 서브셋을 권한다. 전체는 수 MB다
