**"원본에서 다시"** 라고 적힌 다섯은 여기 JPEG로 판단만 하고, 실제로 자를 때는 다운로드의 원본 PNG를 쓴다. 나머지는 어차피 보고 SVG로 옮길 거라 JPEG로 충분하다.

**모든 파일 오른쪽 아래에 생성기 워터마크(✦)가 박혀 있다.** 프롬프트로 막히지 않는다. 알파 마스크로 쓸 13·14·15·16번은 **쓰기 전에 반드시 잘라낸다.**

### 쓰임이 두 가지인 이유

- **밑그림** — 보고 손으로 SVG를 다시 그린다. 이 폴더의 PNG는 앱에 안 들어간다. 글자·치수가 정확해야 하고 다크 모드에서 색이 바뀌어야 하기 때문이다
- **PNG / 알파 마스크 / 타일** — 줄여서 실제로 넣는다. 손으로 못 만드는 질감들이다. WebP로 변환하고 예산 안에서 쓴다
